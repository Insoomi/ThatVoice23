# THATVOICE Website

A responsive, multi-section advocacy organisation website built with plain HTML, CSS, and JavaScript.

## Files

- `index.html` — website content and page sections.
- `style.css` — layout, colours, typography, and responsive design.
- `script.js` — mobile navigation, footer year, and contact-form email preparation.

## How to run it

1. Download and extract the ZIP file, or open the project folder in Visual Studio Code.
2. Open `index.html` in a web browser. You can also use the VS Code Live Server extension.
3. Keep all three files in the same folder.

## Contact form note

The form opens the visitor's default email application using a `mailto:` link. It does not send mail directly or store submissions. To receive form submissions without relying on the visitor's email application, connect a form service or create a backend.

## Publish with GitHub Pages

1. Create a GitHub repository named `thatvoice`.
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository's root folder.
3. Open **Settings → Pages** in the repository.
4. Under build and deployment, choose **Deploy from a branch**, select the `main` branch and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site and use the URL shown in Settings → Pages.

A custom domain such as `thatvoice.org` must be registered separately and configured in GitHub Pages. Check domain availability before buying it.

## Before publishing

- Confirm that the email and phone number are correct.
- Add official social-media links only when available.
- Add real, permission-cleared photos and verified project results when available.
- Add an accurate physical office address only when one is confirmed.
